### Ratings
- APOEL and Omonia stars use **EA's own FC 27 ratings** (Đuričić 75, Négo 73, Laifis 72, …).
- Everyone else is an **estimate inside their tier band**. Key players (David Luiz, Jovetić,
  Goldson, Foderingham…) get the top of the club's curve, but the tier cap still wins.
- Result: best Krasava player is **63**, best Second Division player **60**, best in Cyprus **75**.
- `rating_source` column says which kind each number is: `ea`, `estimate_key` or `estimate`.

## 3. Managers (`clubs.json` → `manager`)

Every First Division club has its head coach. Conflicts between sources are listed in a
`conflict` field. Five need your call: Apollon, Anorthosis, Akritas, Ethnikos, ENP.

**"How they look in game":** FC builds a manager's 3D body/head from generic presets. Real
likenesses only exist for managers EA scanned. What Live Editor *can* do:
1. **Minifaces (portraits in menus):** Live Editor → Managers → Edit → import a photo as the
   miniface. Put photos in `assets/managers/_local/<club_id>.png` (git-ignored).
2. **3D look:** pick the closest generic head, hair, skin tone and suit in the Managers Editor.
   This can't be automated reliably, so it's a manual step per manager.

## 4. Kits & badges

- `clubs.json` → `kit`: colours, manufacturer and sponsor where a source gave them (lots are
  still null). Fields filled from general knowledge rather than a fetched source are listed in `_unverified`.
- **Badges:** `python3 tools/fetch_badges.py` downloads every club crest from Wikipedia into
  `assets/badges/_local/` (git-ignored, personal use). Then import them in **FIFA Editor Tool 2.2**
  → team crest assets. Note: Wikipedia rate-limited our cloud machine, so this needs to run on your PC.
- **Kits:** make them in **FIFA Kit Creator** (FC 27 support confirmed) using the colours in
  `clubs.json`, then import with FIFA Editor Tool. Real kit photos for reference: the club pages and their social media.

## 5. "Manage any team I want" (Career Mode)

**This works today with Live Editor, no mod code needed** (from the Live Editor wiki):

1. Load your career save with Live Editor running.
2. **F9 → Features → Teams →** pick the club you want → **Team → Create Job Offer**.
   Works for **any club and any national team**.
3. In-game: **Manager Market** → accept the offer. National team: **Office → Job Search →
   International**.
4. Optional: **Managers editor → "Unsackable"** so the board can't fire you while you hop around.

Automating it (a menu that lists every club) needs Lua functions the Live Editor docs **don't
document**. We won't guess them. Run `integrations/live-editor/lua/discover_career_events.lua`
(log-only, changes nothing), do one job switch, and send back the log. Then we can build it
properly.

## 7. Turning off Dynamic OVR

FC 27's **Dynamic OVR** moves ratings up and down with form, morale and fitness during
Career Mode. The game has no setting to turn it off. **Live Editor does:** its changelog
lists `Disable Dynamic OVR` under "Miscellaneous Features", added in **v27.1.3**.

1. Run Live Editor **v27.1.3 or newer** and load your career save.
2. **F9 → Miscellaneous Features → Disable Dynamic OVR.**
3. Re-apply it after each game restart unless Live Editor saves it for you (not confirmed).

Version note: Live Editor's `version.json` listed the **public** build as v27.1.0, older than
27.1.3. Until the public build passes 27.1.3, this option may only be in the Patreon builds.
Check your Live Editor version first.

Why it matters for this mod: with Dynamic OVR off, our ratings, the season-1 caps and the
ageing curve stay as set, instead of being moved around by form every week.
